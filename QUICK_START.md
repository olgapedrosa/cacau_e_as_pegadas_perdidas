# 🎮 GUIA RÁPIDO — Cacau e as Pegadas Perdidas

## Início Rápido (Windows)

1. **Abra o arquivo:** `run_server.bat`
2. **Navegador:**  Automaticamente vai abrir `http://localhost:8000`
3. **Clique:** "Começar o passeio"
4. **Use:** WASD para andar, Mouse para olhar

---

## Início Rápido (Mac/Linux)

```bash
bash run_server.sh
# ou
python3 -m http.server 8000
```

Depois abra: `http://localhost:8000`

---

## ⌨️ Controles

| Tecla | Função |
|-------|--------|
| **W** ou **↑** | Andar para frente |
| **S** ou **↓** | Andar para trás |
| **A** ou **←** | Andar para esquerda |
| **D** ou **→** | Andar para direita |
| **Mouse** | Olhar em volta (clique para ativar) |
| **ESC** | Sair do mouse look |

## 💡 Dicas

1. **Iluminação muda:** O "sol" se move ao longo do tempo — observe como as sombras mudam

2. **Busque detalhes:** Aproxime-se de objetos para ler mensagens contextuais

3. **Silhueta misteriosa:** No bosque você pode ver algo se movendo — tente aproximar!

4. **Animações:** Observe a Cacau no final — ela se mexe (cauda, patas)

5. **Água:** Clique e segure o mouse perto do lago para ver a água animada

## 🐛 Se Algo Não Funcionar

### Tela preta
- Seu navegador pode não suportar WebGL 2
- Tente: Chrome, Firefox, Edge (versões recentes)

### Sem imagem
- Recarregue a página (F5 ou Ctrl+R)
- Verifique se o servidor HTTP está rodando

### Mouse não funciona
- Clique no jogo para ativar
- Pressione ESC para desativar

### Câmera travada
- Aguarde 5 segundos (final narrativo)
- Recarregue se ficar preso
